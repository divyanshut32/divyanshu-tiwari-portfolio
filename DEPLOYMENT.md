# Deployment Checklist

## Before deploying
- [ ] Change ADMIN_PASSWORD.
- [ ] Generate a strong SESSION_SECRET.
- [ ] Configure Gmail App Password.
- [ ] Confirm CONTACT_TO.
- [ ] Replace project GitHub links with individual repository URLs.
- [ ] Confirm public name, email, phone and resume match the person.
- [ ] Test the contact form.
- [ ] Test `/admin.html`.
- [ ] Enable persistent storage if using SQLite.

## Domain
After deployment, connect a purchased domain in your hosting provider's dashboard and update DNS records as instructed by the provider.
